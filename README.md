# CodeHire-AI

## AI Powered Code Analysis System

CodeHire-AI is a Python Flask based web application that helps users analyze coding skills and practice programming.

## Features
- User Registration & Login
- Profile Management
- Dashboard
- Coding Result Page
- History
- Forgot Password
- SQLite Database Support

## Technologies Used
- Python
- Flask
- HTML
- CSS
- SQLite

## Project Structure
- app.py
- templates/
- users.db
