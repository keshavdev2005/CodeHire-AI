# CodeHire AI

## Overview
CodeHire AI is an AI-powered code analysis web application built using Python Flask. It helps users analyze code, detect programming languages, calculate complexity, generate AI suggestions, and download PDF reports.

## Features
- User Login & Registration
- Dashboard
- Code Analysis
- Programming Language Detection
- Complexity Analysis
- AI Suggestions
- Analysis History
- PDF Report Download
- Leaderboard
- Profile Page

## Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite
- Chart.js
- ReportLab

## Installation

bash
pip install flask reportlab
python app.py
